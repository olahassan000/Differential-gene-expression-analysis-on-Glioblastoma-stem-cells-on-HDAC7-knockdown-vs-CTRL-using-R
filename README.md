# Differential-gene-expression-analysis-on-Glioblastoma-stem-cells-on-HDAC7-knockdown-vs-CTRL-using-R
RNA-seq differential gene expression was performed in the R Studio platform using DESeq2 for dispersion of RNA seq data and annotated with GENCODE reference annotation for the human hg38 genome.

# Methods:
- R language (R Markdown)
- DESeq2
- Bioconductor
- Pheatmap
- ClusterProfiler
- ggplot2
- enrichplot
- Gene Ontology enrichment
- GSEA
